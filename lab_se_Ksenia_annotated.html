Reading R: the ten things you need

# …
Everything after a # on a line is a note for humans. R skips it.
x <- 5
“Store the value 5 under the name x.” The arrow is how R saves things for later use.
name(...)
A function: a named operation that takes inputs in brackets and gives back a result, e.g. mean(x) returns the average of x.
function(a, b = 2) { ... }
Defines a new, home-made function: a reusable recipe. b = 2 is a default used when no value is given. Nothing happens when it is defined; the recipe runs only when it is later called by name.
c(10, 40)
Combines values into a vector (an ordered list of values).
tibble / list
A tibble is a table: rows are observations, columns are variables. A list is a container that can hold anything, here the sets of 2,000 averages; res$averages[["10"]] pulls out the one named “10”.
d$unvoting
Pulls one column out of a table.
NA, !is.na(x)
NA is R's code for a missing value; ! means “not”, so !is.na(x) means “x is not missing”.
for (k in ns) {...}, replicate(n, {...})
Repetition. A for loop runs the code once for each value in ns; replicate runs it n times and collects the results.
%>%, ggplot(...) + ...
The pipe %>% passes the result of one step on to the next (“and then”). In charts, + adds one layer or setting at a time.

Lines 10–19

Summarises the four steps: take the non-missing values as the population, draw 2,000 samples of 10 and 2,000 of 40, plot the averages and compute their spread, then compare that spread with the textbook formula.

Check: “Sampling WITH replacement … is the standard simple-random-sample model” is not right. A simple random sample normally means drawing without replacement (no state picked twice), which is what the other two submissions did. Drawing with replacement is a legitimate choice, and it is exactly the setting in which sd/√n holds without any correction, but it means a sample of 10 can contain, say, Canada twice. This difference is why this script's numbers match the formula at n = 40 (3.76 vs. 3.66) while the other two fall below it (3.27 vs. 3.67).
21# KEY FORMULAS USED
22#   - sample() draws WITH replacement by default (replace = TRUE).
23#   - The average of a sample of n values = mean() = sum(x) / n.
24#   - Standard deviation of the sample averages = sd(averages).
25#   - Theoretical standard error = sd_pop / sqrt(n), where sd_pop is the
26#     POPULATION standard deviation, computed as sd(x) * sqrt((n-1)/n).
27#     sd(x) uses the (n-1) denominator (sample SD); to get the population
28#     SD we rescale it by sqrt((n-1)/n). For a large population the two
29#     are nearly identical, but we use the exact population value.
30#   - Expected spread of averages for a 0-1 variable (article98) uses the
31#     Bernoulli standard error sqrt(p(1-p)/n) as an alternative check.
32#
Lines 21–31

Lists the formulas the script relies on: the average, the standard deviation of the averages, and the theoretical standard error sd_pop/√n. It explains that R's sd() divides by n − 1, so it rescales to get the “population” standard deviation, which divides by N.

Check: Three small problems in this note. (1) Line 22 says sample() draws with replacement by default. It does not: the default is replace = FALSE. The code works anyway because line 104 sets replace = TRUE explicitly. (2) Line 26 uses n both for the sample size and for the population size, which is confusing; in the code the population size is n_pop (190 or 216). (3) Lines 30–31 present the Bernoulli formula √(p(1−p)/n) as an “alternative check”. For a 0/1 variable it is not a separate check: the population variance of a 0/1 variable is p(1−p), so the two formulas are algebraically identical and always print the same number (they do: 0.1416 and 0.0708).

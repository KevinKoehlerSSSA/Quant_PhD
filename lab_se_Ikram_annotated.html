Reading R: the ten things you need

#
Everything after a # on a line is a note for humans. R skips it.
x <- 5
“Store the value 5 under the name x.” The arrow is how R saves things for later use.
name(...)
A function: a named operation that takes inputs in brackets and gives back a result, e.g. mean(x) returns the average of x.
function(a, b) { ... }
Defines a new, home-made function: a reusable recipe. Nothing happens when it is defined; the recipe runs only when it is later called by name.
c(10, 40)
Combines values into a vector (an ordered list of values).
data frame / tibble
A table: rows are observations (here, states), columns are variables.
d[["unvoting"]], d$country
Two ways of pulling one column out of a table.
NA
“Not available”: R's code for a missing value.
! & |
Logic: “not”, “and”, “or”. !is.na(x) means “x is not missing”.
for (n in sizes) { ... }
A loop: run the code in braces once for each value in sizes.
if (...) { ... }
Run the code in braces only if the condition is true.
cat(), sprintf()
cat prints text to the screen; sprintf("%.4f", x) formats a number with four decimals; \n means “new line”.
library(haven)
Loads an add-on package (a toolbox someone else wrote). haven reads Stata files, ggplot2 draws charts, dplyr manipulates tables.

1# =============================================================================
2# Lab A - Standard errors two ways (sampling distributions of the mean)
3#
4# What this script does:
5#   1. Reads data/Data_2011-07-26.dta (the Goldsmith & Horiuchi replication data).
6#   2. Treats the OBSERVED values of `unvoting` as if they were a whole
7#      population of states. It then draws 2,000 random samples of 10 states,
8#      and 2,000 random samples of 40 states, computes the average of each
9#      sample, and reports how spread out those 2,000 averages are.
10#   3. Compares the simulated spread with the formula  sd / sqrt(n).
11#   4. Repeats all of that for `article98`, where the average of a sample of
12#      0/1 values is exactly the share of states in that sample that signed.
13#   Figures go to output/, so they can be used in the write-up.
14#
Lines 1–14

Header note. A plain-English summary of the whole script, written at the top as comments. It promises four steps: read the data, treat the observed states as the whole “population”, draw 2,000 random samples of 10 and of 40 states and average each one, and compare how spread out those averages are with the textbook formula sd/√n. Then the same for article98.

For a 0/1 variable such as article98 (1 = signed an Article 98 agreement with the US), the average of a sample is simply the share of sampled states that signed.

Reading R: the ten things you need

# …
Everything after a # on a line is a note for humans. R skips it.
x <- 5
“Store the value 5 under the name x.” The arrow is how R saves things for later use.
name(...)
A function: a named operation that takes inputs in brackets and gives back a result, e.g. mean(x) returns the average of x, sd(x) its standard deviation, sqrt(10) the square root of 10.
library(haven)
Switches on an add-on package. haven provides read_dta(), which reads Stata files.
gh$unvoting
Pulls one column (variable) out of the table gh.
NA, is.na(x), !
NA is R's code for a missing value. is.na(x) is TRUE where x is missing; ! means “not”. sum() of TRUE/FALSE values counts the TRUEs.
x[condition]
Square brackets keep only the values for which the condition is TRUE, e.g. gh$unvoting[!is.na(gh$unvoting)] keeps the non-missing values.
sample(x, size = 10, replace = FALSE)
Picks 10 values from x at random. replace = FALSE: no value can be picked twice.
replicate(2000, ...)
Runs the code in brackets 2,000 times and collects the 2,000 results.
png(...), hist(...), dev.off()
Open a picture file, draw a histogram into it, close the file.

A detail

sd() divides by N − 1 (the sample formula). For a full population, dividing by N is strictly correct; with N = 190 the difference is 0.3% and does not matter here.

The formula: population standard deviation divided by √n. 7.34 for n = 10, 3.67 for n = 40.

unvotingsimulatedsd/√nsd/√n × √(1 − n/N)
n = 107.107.347.14
n = 403.273.673.26
Check: The script prints the two sets of numbers but does not compare them, and at n = 40 they differ by 11%. The reason is the sampling choice on line 37: drawing 40 different states out of only 190 covers a fifth of the population, so the averages vary less. The exact formula without replacement multiplies by the finite-population correction √(1 − n/N) = √(1 − 40/190) = 0.89, which gives 3.26 (last column), almost exactly the simulated 3.27. This is the answer to verification question 3, and it is the student's to explain.

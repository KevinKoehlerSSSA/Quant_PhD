x <- 5
“Store the value 5 under the name x.” The arrow is how R saves things for later use.
name(...)
A function: a named operation that takes inputs in brackets and gives back a result, e.g. mean(x) returns the average of x.
function(a, b) { ... }
Defines a new, home-made function: a reusable recipe. Nothing happens when it is defined; the recipe runs only when it is later called by name.
c(10, 40)
Combines values into a vector (an ordered list of values).
data frame / tibble
A table: rows are observations (here, states), columns are variables.

NA
“Not available”: R's code for a missing value.

A loop: run the code in braces once for each value in sizes.

2#
3# What this script does, in plain language:
4#   1. Reads the UN voting data and treats the observed values of two
5#      variables as a FINITE POPULATION of states:
6#        - unvoting  : share of resolutions a state voted "no" on (a percentage)
7#        - article98 : whether a state signed an Article 98 agreement (0/1)
8#   2. For each variable it repeatedly draws simple random samples WITHOUT
9#      replacement: 2,000 draws of 10 states, and 2,000 draws of 40 states.
10#      For every draw it computes the average (the sample mean).
11#   3. It plots the 2,000 sample averages for each sample size as a histogram,
12#      and reports the standard deviation of those 2,000 averages.
13#   4. It compares that simulated standard deviation with the standard error
14#      formula  sd / sqrt(n),  where sd is the (population) standard deviation
15#      of the variable and n is the sample size. This is the FINITE POPULATION
16#      CORRECTION: because we sample a large share of a small population
17#      without replacement, the true standard error is
18#          sd / sqrt(n) * sqrt( (N - n) / (N - 1) ),
19#      which we also report so the two can be compared properly.
20#   5. Repeats everything for article98.
21#
Lines 2–21

Header note. A plain-English summary: read the UN voting data; treat the observed values of two variables as a fixed population of states; draw 2,000 random samples of 10 and of 40 states; average each sample; plot the averages; compare their spread with the textbook formula sd/√n.

It then goes one step further than the task: it introduces the finite population correction, an adjustment to the formula needed when the sample is a sizeable share of a small population and states cannot be drawn twice.

85# simulate_means(pop, n, reps) draws `reps` simple random samples WITHOUT
86# replacement of size `n` from the population `pop`, and returns the average of
87# each sample.
88#
89# Sampling WITHOUT replacement is the realistic setting: you cannot vote twice.
90# In R this is sample(pop, size = n, replace = FALSE). Sampling with replacement
91# would understate the spread when n is a large share of N, because it lets the
92# same state appear twice.
93#
94# The number of replications (reps = 2000) is the number of times we repeat the
95# experiment; each replication is an independent sample.
Lines 85–95

Explains the simulation function.

Check: Two problems in this note. “You cannot vote twice” is a confusing image: the point is that a state cannot appear twice in the *same sample*. More importantly, the claim that sampling *with* replacement “would understate the spread” is backwards: sampling with replacement gives *more* spread (exactly sd/√n), and sampling without replacement gives *less*. The script's own results show this.
